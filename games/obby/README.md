# 🟦 블록 점프맵 (Roblox Style Obby)

별도 설치 없이 **브라우저에서 바로 실행**되는 로블록스 스타일 3D 점프맵 게임입니다.
순수 HTML + JavaScript(Three.js)로 만들어졌습니다.

## 실행 방법

`index.html` 파일을 더블클릭해서 웹 브라우저(Chrome 권장)로 열기만 하면 됩니다.

## 조작법

| 동작 | 키 |
|------|----|
| 이동 | `W` `A` `S` `D` 또는 화살표 키 |
| 점프 | `스페이스바` |
| 카메라 회전 | 마우스 드래그 |

## 목표

지그재그로 놓인 발판을 점프해서 올라가며 **코인 8개를 모두 모으고**,
맨 위 **초록 깃발(결승점)**에 도착하면 클리어! 🎉

발판에서 떨어지면 시작점으로 다시 돌아갑니다.
